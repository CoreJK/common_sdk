# 手眼标定系统改进说明

## 主要改进内容

### 1. 棋盘格配置优化

**原配置:**
- 9x6 角点，25mm方格
- 对应10x7方格

**新配置（适合小视野相机）:**
- 6x4 角点，20mm方格
- 对应7x5方格
- 物理尺寸: 120mm × 80mm

**calib.io 网站生成参数:**
```
Board Width: 7 (方格列数)
Board Height: 5 (方格行数)
Square Size: 20 mm
Units: millimeters
```

### 2. 电机使能自动检查

添加了 `check_and_enable_all_motors()` 函数：
- 在手眼标定前自动检查所有电机使能状态
- 提示用户是否启用未使能的电机
- 验证电机使能操作是否成功
- 避免因电机未使能导致的逆解失败

### 3. 工作空间参数优化

根据 `interactive_robot_work_space.py` 计算结果调整：
```python
# 原参数
workspace_center=[0.15, 0.0, 0.20]
workspace_radius=0.05

# 优化后参数
workspace_center=[0.20, 0.0, 0.15]  # 更接近工作空间中心
workspace_radius=0.08              # 增大半径，更好利用工作空间
```

### 4. 手动拖动标定模式

新增 `manual_hand_eye_calibration()` 函数，支持：
- 手动拖动机械臂到不同位姿
- 实时相机预览和标定板检测
- 交互式数据采集流程
- 自动卸载电机使能以便手动操作

**使用流程:**
1. 选择标定模式（自动/手动）
2. 手动模式下卸载电机使能
3. 拖动机械臂到新位姿
4. 按Enter键采集当前位姿数据
5. 重复采集10-15个位姿
6. 输入'done'完成采集并计算标定

## 使用建议

### 棋盘标定板制作
1. 使用激光打印机高精度打印
2. 贴在平整硬板上（亚克力或木板）
3. 用卡尺测量实际方格尺寸，确保为20mm
4. 避免反光和阴影

### 标定模式选择
- **自动模式**: 电机正常工作，系统自动控制运动
- **手动模式**: 电机有问题或需要精确位姿控制时使用

### 位姿采集技巧
1. 确保每个位姿下标定板完全可见
2. 变化距离、角度和方向
3. 避免运动模糊
4. 采集10-15个有效样本

## 注意事项

1. **电机安全**: 手动模式下注意机械臂突然掉落
2. **相机焦距**: 确保所有位姿下标定板都清晰对焦
3. **标定精度**: 建议重投影误差 < 1.0 像素
4. **工作空间**: 避免接近关节限位的极端位姿

## 错误处理

常见问题及解决方案：
- **逆解失败**: 检查电机使能状态，选择手动模式
- **标定板检测失败**: 调整光照，确保标定板平整
- **标定精度低**: 增加采样点数量，改善位姿分布
