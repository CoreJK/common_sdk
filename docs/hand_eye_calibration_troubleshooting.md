- **目标位姿**: 15个

这表明问题出现在**数据采集阶段**，而非标定算法本身。

## 🔍 自动诊断工具

我们已为您添加了自动诊断功能：

```python
# 当标定失败时，程序会自动运行诊断
```

诊断项目包括：
1. **电机使能状态检查**
2. **相机连接状态检查** 
3. **机械臂工作空间检查**
4. **标定板检测检查**

## 🛠️ 常见问题及解决方案

### 1. 电机使能问题 ⚡

**症状**: 机械臂无法移动到目标位姿，逆解失败

**检查方法**:
```bash
# 查看电机状态
controller.get_all_joints_load_status()
```

**解决方案**:
- 确保所有关节(1-6)都已使能
- 运行程序时选择自动启用电机
- 手动启用: `controller.set_all_joints_load_status(1)`

### 2. 工作空间问题 📐

**症状**: 目标位姿超出机械臂可达范围

**原因分析**:
- 工作空间参数设置不当
- 当前位姿距离工作中心过远
- 关节限位约束

**解决方案**:
```python
# 优化工作空间参数
workspace_center=[0.20, 0.0, 0.15]  # 调整中心位置
workspace_radius=0.06              # 减小半径
```

### 3. 标定板检测问题 👁️

**症状**: 相机无法检测到标定板角点

**检查清单**:
- [ ] 标定板是否在相机视野内
- [ ] 标定板尺寸配置是否正确 (6x4角点)
- [ ] 光照条件是否适宜
- [ ] 标定板是否平整、清洁

**解决方案**:
```python
# 检验标定板配置
board_size = (6, 4)     # 6x4角点
square_size = 0.020     # 20mm方格
```

### 4. 相机标定问题 📷

**症状**: 相机内参不准确影响位姿估计

**检查方法**:
- 查看相机标定的重投影误差 (应 < 1.0像素)
- 确认标定图像质量和数量 (≥10张)

**解决方案**:
- 重新进行相机标定
- 使用更多、更好的标定图像
- 检查相机焦距是否固定

## 🎯 推荐的排查流程

### 步骤1: 运行自动诊断
```bash
python examples/eye_in_hand_calibration_example.py
# 当标定失败时会自动运行诊断
```

### 步骤2: 根据诊断结果修复问题

**如果电机问题**:
1. 检查电源和连接
2. 确认串口权限
3. 启用必要的关节

**如果工作空间问题**:
1. 手动移动机械臂到中心位置
2. 调整工作空间参数
3. 检查关节限位设置

**如果检测问题**:
1. 调整标定板位置
2. 改善光照条件
3. 清洁标定板表面

### 步骤3: 使用手动模式验证

如果自动模式持续失败，尝试手动模式：
```python
# 选择手动标定模式
# 程序会提示选择：1=自动，2=手动
# 选择 2 进入手动模式
```

手动模式优势：
- 完全控制机械臂位姿
- 实时查看标定板检测状态
- 避免逆解失败问题

## 📊 成功标定的条件

### 最低要求
- ✅ 至少5个关节使能
- ✅ 相机能正常获取图像
- ✅ 能检测到标定板角点
- ✅ 机械臂在工作空间内

### 推荐配置
- 📍 采集10-15个不同位姿
- 📍 旋转角度变化 > 30度
- 📍 位置变化覆盖工作空间
- 📍 所有位姿下标定板完全可见

### 质量指标
- 🎯 重投影误差 < 1.0像素
- 🎯 位置误差 < 2.0mm
- 🎯 角度误差 < 2.0度

## 🚀 快速修复建议

### 1. 立即检查项

### 2. 常用修复命令
```python

controller.set_all_joints_load_status(1, include_gripper=True)

# 移动到安全位置
safe_pose = [0.20, 0.0, 0.15, 0.0, 0.0, 0.0]
controller.set_joint_move_with_coordinate(safe_pose)

# 重新初始化相机
cap.release()
cap = cv2.VideoCapture(camera_source)
```

### 3. 参数调优

```python
# 增加超时时间
```
